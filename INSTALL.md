# Install on GitHub

**Upload the entire contents of this package to the root of `vassellenha/vassellenha`.** Do not upload only README.md.

Required structure:

```text
README.md
assets/
  ccell-hero.gif
  ccell-hero-preview.png
  section-01.svg ... section-05.svg
  project-brread.png
  project-catchclash.png
  development-loop.svg
  footer.svg
```

On GitHub, choose **Add file > Upload files**, then drag the extracted README.md AND the `assets` folder (its contents and folder paths must be preserved). Commit changes. The new README references `./assets/...` files from the repository root.

Verify these links after upload:

- https://github.com/vassellenha/vassellenha/blob/main/assets/ccell-hero.gif
- https://github.com/vassellenha/vassellenha/blob/main/assets/development-loop.svg
- https://github.com/vassellenha/vassellenha/blob/main/assets/project-brread.png

If GitHub did not preserve the directory, open the repository's `assets/` directory, click **Add file > Upload files**, and upload the files inside it.

This is a real GitHub README: animated GIF, clickable links, in-page anchor navigation, and native expandable sections. GitHub does not support JavaScript/JS-driven filters/scroll effects in READMEs.

The ASA portrait is loaded from the Sony Music URL already used in earlier versions. If Sony Music changes its image URL, this one external picture may stop loading; no ASA labels/fandom text are included. The streak chart and icon/badge services are external services.
